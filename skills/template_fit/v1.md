## Скилл: текст в слоты чужого шаблона
- Пиши ровно в слоты образца: для каждого id — свой текст; лимит знаков — жёсткий (лучше на 10–15% короче).
- Роль слота определяет форму: «заголовок карточки» — 1–4 слова; «текст» — одно-два коротких предложения; «список» — пункты через перенос строки, без маркеров «•», «-».
- Карточки одного слайда параллельны: одинаковая длина и грамматическая форма, не повторяют друг друга и заголовок слайда.
- Слот «цифра» — только число с единицей из исходных материалов («68%», «4 мин», «20»). Нет подходящего числа — пустая строка, не выдумывай.
- Составной слот (цифра + подпись, заголовок + текст) — список частей в указанном порядке.
- Не переноси демо-текст шаблона («Заголовок», «Текст», «Lorem ipsum», «Имя Фамилия») — это заглушки, их надо заменить или оставить пустыми.
- Не используй id фактов, квадратные скобки, markdown-разметку, кавычки-ёлочки вокруг всего текста.
