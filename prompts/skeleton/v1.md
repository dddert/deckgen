## Правила каркаса
1. Первый слайд — title (название колоды + подзаголовок в points[0]). Последний — thanks, если он есть в шаблоне; перед ним — cta или итоговый слайд с призывом к действию.
2. kind — только из списка выше. Для cards / factoids / process / agenda / team укажи n_items — сколько элементов нужно (из доступных в шаблоне), и столько же points.
3. factoids — только если есть 2+ цифры из фактов: points вида «68% — используют ежедневно», fact_refs обязательны.
4. chart/table — только с data_ref на таблицу; chart_type по правилам визуализации.
5. points — черновые тезисы, каждый до 12 слов, без цифр, которых нет в материалах.
6. image — короткое описание иллюстрации (что изобразить), только для слайдов, где картинка усиливает мысль; иначе null.
7. Не повторяй мысли между слайдами; соседние слайды связаны.
